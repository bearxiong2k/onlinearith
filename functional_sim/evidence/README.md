# Functional evidence

This directory holds small, already-committed examples from the frozen
functional workflow. It is not the default destination for new generated
results.

- [`smoke_runs/`](smoke_runs/README.md): historical limited-run JSON/JSONL
  examples moved out of the repository root during reorganization.

Final paper values must continue to cite their original experiment protocol,
model revision, calibration artifact, and full-versus-sampled scope. Moving an
example here does not upgrade its evidence strength.
