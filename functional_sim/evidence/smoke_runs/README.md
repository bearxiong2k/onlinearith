# Historical smoke-run examples

These files predate the functional/hardware split and were already tracked.
They are retained for provenance and parser examples:

- `ppl_setup2_gpu4_limit2.json`
- `ppl_setup6_gpu4_compile_limit80.json`
- `ppl_setup6_gpu5_compile_limit2.json`

generated outputs remain ignored and should not be committed unless the user
explicitly requests an evidence snapshot.
