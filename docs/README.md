# Shared documentation

This directory contains paper-wide guidance, curated writing evidence, and
historical material.
Each simulation workstream owns its detailed documentation next to its code.

- [Functional-simulation documentation](../functional_sim/docs/README.md)
- [Hardware-simulation documentation](../hardware_sim/docs/README.md)
- [Writing workspace and source index](paper/README.md)
- [Historical archive](archive/README.md)

Do not place new hardware design contracts in this shared directory. Put them
under `hardware_sim/docs/` so the active hardware context stays self-contained.
