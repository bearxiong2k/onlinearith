# Paper-wide documentation

This directory holds writing guidance that spans both the frozen numerical
evidence and the new hardware evaluation.

- [Revision lessons from the rebuttal](revision_lessons_from_rebuttal.md):
  reviewer concerns, reusable evidence, revised claim boundaries, and the
  figure/table plan after the hardware redesign.

Numerical claims must cite the frozen functional provenance. Hardware claims
must cite the new hardware ledger, RTL, synthesis, or explicitly labeled
formula source. A table may combine them, but it must not imply that they came
from one simulation run.
